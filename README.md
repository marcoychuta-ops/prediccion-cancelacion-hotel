# Predicción de Cancelación de Reservas Hoteleras

## Descripción

Este proyecto desarrolla un modelo de Machine Learning para predecir la probabilidad de cancelación de reservas hoteleras utilizando Python y algoritmos de clasificación.

## Objetivo

Desarrollar un modelo que permita predecir la probabilidad de cancelación de una reserva hotelera.

## Dataset

- **Nombre:** Hotel Booking Demand Dataset
- **Registros:** 119,390 reservas
- **Variables:** 36 características

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Modelos implementados

- Decision Tree
- Random Forest
- XGBoost

## Métricas de evaluación

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Archivos del proyecto

- 📓 `CANCELACIONES_HOTEL.ipynb` → Desarrollo completo del modelo.
- 📊 `hotel_booking.csv` → Conjunto de datos.
- 🌐 `dashboard_cancelaciones_hotel_final.html` → Dashboard interactivo.
